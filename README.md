# Nexus Studio — site público

Versão compilada do editor visual de jogos 2D Nexus Studio.

Acesse: https://riqueolendario2024.github.io/nexus-studio-site/

O projeto original é mantido em um repositório privado. Este repositório contém os arquivos servidos ao navegador.

Os jogos criados são salvos neste navegador. Para transferir um jogo de outro endereço, exporte e importe o arquivo de projeto.
